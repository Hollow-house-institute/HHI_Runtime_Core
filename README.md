# HHI Runtime Core

HHI Runtime Core is the consolidated execution-time governance runtime for Hollow House Institute.

It provides shared infrastructure for:

- governance telemetry
- replay continuity
- audit evidence
- runtime proof
- workflow orchestration
- interaction controls
- authority propagation
- continuous assurance
- runtime observability

## Doctrine

Governance that cannot survive replay, migration, restart, or audit is not operational governance.
